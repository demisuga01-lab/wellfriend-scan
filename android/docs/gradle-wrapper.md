# Gradle wrapper provenance

The committed wrapper uses Gradle 8.7, compatible with Android Gradle Plugin
8.6.1. It was generated by the official Gradle 8.7 distribution, verified before
generation against the official `gradle-8.7-bin.zip.sha256` value:

```text
544c35d6bd849ae8a5ed0bcea39ba677dc40f49df7d1835561582da2009b961d
```

`gradle-wrapper.properties` pins the same HTTPS distribution URL and checksum.
It allows a 60-second initial download for constrained networks.
Run `./gradlew` on POSIX or `gradlew.bat` on Windows. Use JDK 17 for this Android
Gradle Plugin version; newer JDKs may not be supported by Gradle 8.7.
